# Board Arena Online v3.3.0

在原有 v2.7 功能基礎上擴充多模式，保留原功能：中國象棋、快速匹配、猜拳先手、選色、30 秒回合、悔棋、求和、再戰邀請、斷線判勝、玩家名字/頭像、聊天室、戰績與將軍動畫/語音。

## 多模式
- 中國象棋
- 15×15 五子棋
- 19×19 圍棋
- 線上房間、快速匹配、人機三種模式均可選遊戲模式
- AI：簡單／普通／困難；修正 AI 回合條件，三種模式都會實際落子

## 圍棋規則依使用者提供的規格書
- 19×19、361 交叉點；欄位 A-T 並跳過 I，縱列 1-19。
- 黑先白後、每回合可落子或 Pass。
- 正交相鄰形成棋組，共享氣；零氣立即提子。
- 自殺禁著：落子後自身無氣且沒有提掉對方時禁止。
- 全盤同形禁重複（Positional Superko）。
- 連續兩次 Pass 進入終局結算。
- 支援終局死棋標記與雙方確認。
- 中國數子法（Area Scoring）；黑貼 3.75。

## 本次修正
- 修正 AI 永遠不走棋的回合條件。
- 圍棋從錯誤的 9×9 改為規格要求的 19×19。
- AI 圍棋遵守自殺禁著與全盤同形檢查。
- 加入終局死棋標記／雙方確認。
- 保留原網站與帳號資料邏輯，不刪除原有功能。
- 附 `go-ai-regression-test.js` 進行 AI 與圍棋核心規則回歸測試。

## v3.0 本次更新
- 五子棋與圍棋改為「線與線交叉點」落子，棋子不再位於格子中央。
- 圍棋依使用者提供的終局規格：雙 Pass 進入結算、認輸立即結束；死棋標記後移除計算；中國數子法；白方 +3.75 貼目；黑方原始數子需 >184.25（至少185）才判黑勝。
- 其他既有功能保持不變。

## v3.1 新增
- 所有模式皆可使用觀戰模式；輸入房間的觀戰碼加入，觀戰者不佔用兩個玩家席位。
- 觀戰者為唯讀，不可走棋、悔棋、求和、投降或干擾對局。
- AI 房與快速匹配房也會產生觀戰碼，玩家可在對局頁複製分享。
- 中國象棋加入移動軌跡動畫；車以滑動為主，炮吃子以跳吃動畫呈現，馬有跳躍感，兵有短促步進。
- 五子棋與圍棋的最新落子加入輕量落點動畫，不改變原有規則。


## v3.3 新增棋類（依使用者提供規格書）
- 明棋：4×8，共32顆；首位玩家第一次翻出的棋子決定其陣營；每回合翻/走/吃三選一，不連吃。
  - 規格書明確寫32顆，但未另外列出每種棋子的數量，也未定義「炮」的吃子規則；為保持32顆，我加入每方2枚炮，並依文件「所有棋子只能上下左右正交相鄰」及階級邏輯，讓炮按與車同級、相鄰吃子處理。這一點屬於為填補規格空缺所做的明確實作約定。
- 暗棋（連吃版）：4×8；已翻開的棋子可連續吃已翻開或暗棋；遇到較大的暗棋時翻開並中斷連吃。
- 多人跳棋：支援2/3/4/6人；六方向單步、等距跳躍、可連跳且不吃被跳過棋子；第一位把自己的棋子全部送入目標大本營者勝。
- 新增模式也可進入人機、快速匹配、觀戰與多人房間。
- 2人跳棋依規格使用15子；6人使用10子；3/4人採10子對稱營區配置（原規格未明定3/4人子數）。


## v3.3 更新
