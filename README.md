# 中國象棋 Online

依照使用者提供的中國象棋規則製作。

## 線上對戰流程
1. 玩家 A 建立房間。
2. 玩家 B 輸入房號加入。
3. 雙方只能先猜拳，棋盤在此階段不能走棋。
4. 猜拳平手：畫面顯示「平手！請再猜一次」，雙方重新猜拳。
5. 猜拳獲勝者：可以選擇自己要當紅方或黑方。
6. 猜拳落敗者：顯示「等待對方選擇象棋顏色」，自動取得另一個顏色。
7. 顏色決定後，猜拳獲勝者先手；即使他選黑方，也由黑方先走。
8. 顏色決定前伺服器會拒絕所有走棋指令。

## 棋規
9×10 棋盤、標準 32 子、車馬象士將炮兵/卒，以及檔案指定的炮架、馬腿、象眼、九宮、河界與直接吃將規則。

## 執行
`npm install` → `npm start`

可部署至支援 Node.js + WebSocket 的雲端平台。

## 發佈到 Render

專案根目錄已包含 `render.yaml`，可直接用 Render Blueprint 建立 Web Service：

1. 將此資料夾推送到自己的 GitHub 儲存庫。
2. 在 Render 建立 Blueprint，選取該儲存庫並部署。
3. 部署完成後，Render 提供的 `https://...onrender.com` 網址就是可分享的遊戲連結。

此專案使用 WebSocket，不能部署到只有靜態檔案的 GitHub Pages。若要讓網站持續在線，請在 Render 選擇不會休眠的服務方案；目前的房間與對局資料只會保留在伺服器記憶體中，伺服器重新啟動後會自動清除。
