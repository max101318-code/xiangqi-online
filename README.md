# 中國象棋 Online v2

依使用者提供的中國象棋規則製作，包含雙人房間與單人 AI。

## 本版新增
- 首頁與玩家頭像選擇（瀏覽器 LocalStorage）
- 房間大廳
- 雙人猜拳 → 猜拳勝者選紅／黑 → 勝者先手
- 單人 AI：簡單／普通／困難
- 30 秒每回合倒數；超時判負
- 悔棋請求／接受／拒絕
- 求和請求／接受／拒絕
- 雙人斷線判另一方獲勝
- 再戰邀請；接受後重新猜拳
- 棋盤移動／吃子音效（Web Audio）
- 將軍：毛筆字動畫 1.5 秒＋瀏覽器機械語音「將軍」
- 將帥照面可視為將軍，對面無子時可沿直線直接吃將／帥

## 啟動
Node.js 18+

```bash
npm install
npm start
```

開啟 `http://localhost:3000`

## Render
Build Command: `npm install`
Start Command: `npm start`
Plan 可使用 Render 提供的免費方案（如帳號介面仍提供）。


## 修正
再戰邀請現在只會由已結束的雙人對局送出；進入房間、重新開局或尚未結束的對局都會自動隱藏再戰邀請。
