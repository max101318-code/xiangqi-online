# 棋戰 Online v2.8.1

同一個網站支援：
- 中國象棋
- 五子棋（15×15）
- 圍棋（9×9，含提子、禁入自殺、簡單打劫、停手終局計分）

## 模式
首頁可分別選擇「線上模式」與「人機模式」的棋種；人機三種模式都可選簡單／普通／困難。

## 線上對戰
- 建立房間／房號加入
- 快速匹配會按「棋種」分池，只配對相同模式
- 中國象棋：猜拳 → 猜拳勝者選紅／黑 → 猜拳勝者先手
- 五子棋／圍棋：猜拳勝者執黑先手
- WebSocket 即時同步
- 對局聊天室，玩家名字與已儲存頭像同步顯示
- 對方斷線，留下玩家直接獲勝
- 再戰邀請

## 玩家資料與戰績
- 名字可儲存
- 頭像可選內建或上傳圖片後按「儲存頭像」
- 已儲存的名字與頭像會送進所有模式（中國象棋／五子棋／圍棋／人機）
- 戰績共用同一個 localStorage 玩家資料：所有模式勝場、敗場、總場數加總
- 每個完成對局只計一次，不會因斷線／重繪／重複訊息重複累加
- 和棋也會增加總場數，但不增加勝場或敗場
- 勝率 = 總勝場 ÷ 總場數 × 100%

## 中國象棋
沿用專案原本的特殊規則，包括：
- 9×10 棋盤
- 標準 32 子
- 炮架、馬腿、象眼、河界、九宮
- 將帥照面可形成攻擊
- 將帥照面時將／帥可像車一樣直線直接吃掉對方將／帥
- 將軍動畫 1.5 秒＋語音

## 五子棋
- 15×15
- 黑白落子
- 橫、直、斜任一方向形成五子即勝
- 棋盤填滿無五連則和棋

## 圍棋
- 9×9
- 黑白輪流落子
- 提子
- 自殺禁手
- 簡單 ko 禁止立即回提
- 雙方連續停一手後結束並計算簡單地盤＋棋子＋提子分數

## 部署
Render：
- Build Command: `npm install`
- Start Command: `npm start`

GitHub 更新後，Render 可自動部署。

## 注意
玩家資料與戰績目前存在瀏覽器 `localStorage`，不是雲端會員資料庫；換裝置或清除網站資料後不會同步。


## v2.8.1 修正
