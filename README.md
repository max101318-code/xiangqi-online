# 棋局 Online v2.8

本版本以使用者提供的 v2.7 專案為基礎，保留原有中國象棋功能，並新增多模式。

## 模式
- 中國象棋：保留猜拳、勝者選紅黑、特殊將帥照面、直接吃將、將軍動畫＋語音、30 秒倒數、悔棋／求和、再戰、斷線判勝與聊天室。
- 五子棋：15×15、黑白輪流、五連勝、滿盤和棋。
- 圍棋：9×9、提子、自殺禁手、簡單打劫、停手與區域計分（含簡化計分）。

## 雙人
- 建立房間／加入房間。
- 快速匹配依遊戲模式分開排隊，不會把不同遊戲配在一起。
- 兩人加入後猜拳決定先手；猜拳平手會重猜。
- 猜拳勝者可以選棋色，勝者先手。
- 對局聊天、悔棋請求、求和請求、再戰邀請。
- 對手斷線時，留下者由伺服器判定勝利。

## 單人
- 三種遊戲都可以選。
- 每種遊戲均有簡單／普通／困難三種 AI 難度。

## 玩家資料與戰績
- 名字與頭像分開儲存。
- 自訂圖片頭像會縮圖後保存。
- 進入任何模式、人機或雙人對局都沿用已儲存頭像。
- 勝場、敗場、和棋、總場數為全部遊戲模式共用統計。
- 勝率 = 總勝場 ÷ 總場數 × 100%。
- 每個對局以唯一 roundKey 去重，避免同一局重複計算。

## 執行
Node.js 18+，執行 `npm install` 後 `npm start`。
