# Board Arena Online v3.4

在 v3.3.1 基礎上，保留既有中國象棋、五子棋、圍棋、觀戰、聊天、頭像、戰績、快速匹配、AI、再戰、悔棋／求和等功能；本版只針對明棋、暗棋與多人跳棋做棋盤與流程優化。

## 明棋／暗棋
- 4×8 方格盤，共 32 顆棋。
- 32 顆未翻開棋子以與中國象棋相同風格的圓形棋子呈現。
- 明棋：翻／走／吃，每回合只能做一種動作，禁止連吃。
- 暗棋：保留連吃與遇到更大暗棋時翻開並中斷的邏輯。

## 多人跳棋
- 2 或 3 人。
- 棋盤為六角星：六個等邊三角形 + 中央正六邊形，六個臂以紅／藍／綠三色呈現。
- 所有 121 個棋孔之間會畫出清楚的六方向連線。
- 行棋可單步，也可等距跳躍；跳棋連跳不吃子。
- 三人局先猜拳決定排名：第 1 名選第一個顏色、第 2 名選第二個顏色，第 3 名自動使用剩餘顏色。
- 兩人局同樣先猜拳，第 1 名先選顏色，第 2 名再選顏色。
- AI 跳棋同樣會先猜拳，然後依序處理顏色選擇。

## 軌跡
- 明棋／暗棋：翻棋有翻面動畫；移動／吃棋有圓棋子滑動與吃棋回彈效果。
- 跳棋：單步滑動；跳躍會有拋物線跳躍感；連跳每一步都會播放軌跡。
- 原有中國象棋車、炮、馬等軌跡不修改。
